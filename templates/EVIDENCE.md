# Verification record

- Feature:
- Commit or working-tree revision:
- Engine/tool versions:
- Reviewer: independent / self-review
- Environment and configuration:

## Checks

For each check record: scenario or exact command; expected result; observed result; PASS / FAIL / BLOCKED / NOT RUN / NOT APPLICABLE; actual evidence path if any.

## Findings and limitations

List reproducible failures, unrun stages, and remaining risks. Never paste secrets or invent evidence.

## User handoff

Changed files and why; how to observe the feature; smallest next step.
